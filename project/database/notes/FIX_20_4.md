## PHẦN III — GHI CHÚ KỸ THUẬT

### Pattern UUID cho stored procedures

Khi bảng PK là `CHAR(36)`, thay thế `LAST_INSERT_ID()` bằng:

```sql
DECLARE v_xxx_id CHAR(36);
SET v_xxx_id = UUID();
INSERT INTO table (id, ...) VALUES (v_xxx_id, ...);
SELECT v_xxx_id AS id;
```
